# Setup

1. Install [Racket - SICP Language](https://docs.racket-lang.org/sicp-manual/index.html) for using Lisp programming language in SICP
2. Add `racket` binary to your `$PATH`
3. [Optional] Install [Code Runner](https://github.com/formulahendry/vscode-code-runner) VSCode extension if you're using VSCode, then you're able to run these `.rkt` file in VSCode within a single click.
